# theill/iquomi — weight keeper

`theill__weight-keeper.xsn` is taken unchanged from
[github.com/theill/iquomi](https://github.com/theill/iquomi), which is MIT licensed. Its
copyright notice and licence text are in [`LICENSE`](LICENSE), copied unchanged from that
repository's `LICENSE` on 2026-11-11.

It is here because it is a real, minimal InfoPath 2003 form written by someone else, and it keeps
the parser honest: it is older and simpler than anything in `samples/own/`, with a different root
schema and a single view.
