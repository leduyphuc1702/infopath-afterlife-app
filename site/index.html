# Purchase Request: form documentation
 
## What the form is
 
- **Name:** Purchase Request
- **File:** `04-purchase-request.xsn`
- **Version:** 1.0.0.1
- **Made with:** InfoPath 2013
- **Views:** 1: Request
- **Counts:** 16 fields, 3 rules, 4 calculations, 3 validations, 2 data connections
- **Records loaded:** 20

## Logic
 
### When the form opens
 
- No rule runs when the form opens.
- 4 calculated fields are worked out from their inputs.
 
### Rules
 
- Rule “Query budget service” runs when the button “Check budget” on view “Request” is pressed: it sets Cost Center in data connection “BudgetService” from Cost center, queries data connection “BudgetService” and sets Budget remaining (web service) from Get Remaining Budget Result in data connection “BudgetService”.\

Questions

Start with one file

Where do my forms go?

Nowhere. The page's policy blocks network requests.

Where is the library kept?

In this browser. Back up saves all of it as one .zip.

What in a form does not run?

Code-behind and ActiveX. Data connections are never called.

Which InfoPath files does it open?

.xsn and .xml files, a folder of them, or a .zip.

Does it move forms to Jira?

No. A separate app does, and Triage plans the waves.
